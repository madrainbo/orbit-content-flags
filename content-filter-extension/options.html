Claim lookup (optional)

Off unless you add a key. With a key saved, selecting text and choosing "Check this claim" from the right-click menu sends only the selected text to Google's Fact Check Tools service and lists any published fact-checks. The key stays on this device and does not sync.

Domain lists

One domain per line; subdomains are included. Allow beats block, and block beats warn. Up to 300 per list.
